# Chunk Mob Challenge 1.0.0

Erste öffentliche Beta-Version der sessionübergreifenden Chunk Mob Challenge.

## Highlights

- Solo- und Koop-Runs mit gemeinsamen oder parallelen Chunk-Runden
- individuelle 16×16-Worldborder pro Teilnehmer
- zufälliger, versionsabhängiger Mobpool mit gleicher Wahrscheinlichkeit
- vollständige Wiederaufnahme nach Logout und Serverneustart
- persistierte Positionen, Mob-UUIDs, Lebenspunkte, Varianten und Statistiken
- Schutz gegen Teleports, Enderperlen, Chorusfrüchte und Portale während einer Runde
- besondere Behandlung für Wither, Warden, Flugmobs und Challenge-Enderdrachen
- optionales Nametag, Glowing und Bossbar über `/cc`
- Hardcore-Niederlage und Sieg durch den echten Vanilla-Enderdragon

## Kompatibilität

Dasselbe Plugin-JAR unterstützt:

- Paper 26.1.2 mit Java 25
- Paper 26.2 mit Java 25

Folia, Spigot und andere Serverplattformen werden nicht unterstützt.

## Installation

1. Paper vollständig stoppen.
2. `chunk-mob-challenge-1.0.0.jar` in den Ordner `plugins` kopieren.
3. Server starten und als Operator `/cc start` ausführen.

Zum Pausieren eines laufenden Runs den Paper-Server mit `stop` beenden. Der
Plugin-Befehl `/cc stop` löscht den Run dagegen bewusst.

> **Beta-Hinweis:** Vor längeren Runs Weltordner und
> `plugins/ChunkMobChallenge` gemeinsam sichern.
